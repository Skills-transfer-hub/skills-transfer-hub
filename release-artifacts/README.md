# Release artifacts — Homebrew tap & Scoop bucket promotion

Per-release Homebrew formula and Scoop manifest are auto-generated by GoReleaser
and published as release assets (`sth.rb`, `sth.json`). They are **NOT** auto-pushed
to the tap/bucket repos. Promotion is manual so we keep eyes on what gets
published during Alpha.

## One-time setup

Create the two distribution repos (public, empty initialiser) under your GitHub
account:

```bash
gh repo create Grandpied33/homebrew-sth --public --description "Homebrew tap for sth"
gh repo create Grandpied33/scoop-sth    --public --description "Scoop bucket for sth"
```

Then bootstrap each from the templates in this folder:

```bash
git clone https://github.com/Grandpied33/homebrew-sth.git ../homebrew-sth
cp -r release-artifacts/homebrew-sth/* ../homebrew-sth/
(cd ../homebrew-sth && git add -A && git commit -m "bootstrap tap" && git push)

git clone https://github.com/Grandpied33/scoop-sth.git ../scoop-sth
cp -r release-artifacts/scoop-sth/* ../scoop-sth/
(cd ../scoop-sth && git add -A && git commit -m "bootstrap bucket" && git push)
```

The placeholder `Formula/sth.rb` and `bucket/sth.json` files are valid enough to
clone from; they'll get overwritten with real content on the first release sync.

## Per-release sync (after each `git tag` + GoReleaser run)

Once the GitHub release for `vX.Y.Z` is published with all assets (binaries,
SHA256SUMS, sth.rb, sth.json), promote to brew/scoop:

```bash
TAG=v0.1.0-alpha.1   # set to the release you just published
gh release download "$TAG" -p sth.rb -p sth.json -D /tmp/sth-release

# Homebrew tap
cp /tmp/sth-release/sth.rb ../homebrew-sth/Formula/sth.rb
(cd ../homebrew-sth && git commit -am "sth $TAG" && git push)

# Scoop bucket
cp /tmp/sth-release/sth.json ../scoop-sth/bucket/sth.json
(cd ../scoop-sth && git commit -am "sth $TAG" && git push)
```

Verify post-push:

```bash
brew tap grandpied33/sth
brew install grandpied33/sth/sth
sth version    # should print the new tag

scoop bucket add sth https://github.com/Grandpied33/scoop-sth
scoop install sth
sth version    # should print the new tag
```

## Why manual?

GoReleaser can auto-PR the formula and manifest (set `skip_upload: false` and
provide a tap PAT in `HOMEBREW_TAP_GITHUB_TOKEN`). We deliberately stay manual
during Alpha because each release may need a quick validation before exposing it
to brew/scoop users — the gate Alpha refuses to run on outdated binaries, so a
broken release pushed to brew is more painful to recover from than a broken
release sitting only in GitHub Releases.

Switch to auto-PR by editing `.goreleaser.yaml`:

- `brews[0].skip_upload: false` (and add `git: ssh` config or a token)
- `scoops[0].skip_upload: false` (same)
