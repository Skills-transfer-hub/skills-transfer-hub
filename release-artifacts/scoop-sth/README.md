# scoop-sth — Scoop bucket for sth

Install:

```powershell
scoop bucket add sth https://github.com/Grandpied33/scoop-sth
scoop install sth
```

Upgrade:

```powershell
scoop update sth
```

Source repo: <https://github.com/Grandpied33/skills-transfer-hub>

## Manifest updates

Each `sth` release publishes a fresh `sth.json` as a GitHub release asset. The
file in `bucket/sth.json` here is updated manually after each release; see the
sync instructions in the `release-artifacts/README.md` of the source repo.
