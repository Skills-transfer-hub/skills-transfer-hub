# homebrew-sth — Homebrew tap for sth

Install:

```bash
brew install grandpied33/sth/sth
```

Upgrade:

```bash
brew upgrade grandpied33/sth/sth
```

Source repo: <https://github.com/Grandpied33/skills-transfer-hub>

## Formula updates

Each `sth` release publishes a fresh `sth.rb` as a GitHub release asset. The
file in `Formula/sth.rb` here is updated manually after each release; see the
sync instructions in the `release-artifacts/README.md` of the source repo.
