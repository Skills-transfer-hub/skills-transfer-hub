# Security policy

## Reporting a vulnerability

Report suspected CLI vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/Skills-transfer-hub/skills-transfer-hub/security/advisories/new).
Do not post exploit details, credentials, or private data in public issues,
pull requests, or discussions. If the private form is unavailable, do not
substitute a public report containing sensitive details.

Include the STH version or commit, operating system, affected command,
reproduction steps using synthetic data, and the expected security impact.
Redact credentials and personal information from logs and attachments.

## Fixes and disclosure

Security fixes target the latest stable CLI release. Reports affecting older
versions are welcome, but older release lines have no guaranteed backports.
Maintainers coordinate fixes and disclosure through the private report.
Release archives and checksum signatures remain distributed through
[sth-releases](https://github.com/Skills-transfer-hub/sth-releases/releases).
